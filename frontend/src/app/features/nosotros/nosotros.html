Sobre DonaConecta

Una comunidad, muchas manos, un mismo propósito.

DonaConecta es un proyecto académico de Ingeniería de Sistemas e Informática de la Universidad Continental, pensado para Huancayo, Junín.

Buscamos ordenar la solidaridad comunitaria para que los bienes materiales lleguen a comedores, albergues y refugios con información clara y seguimiento responsable.

Cómo usar DonaConecta

Explora hoy, participa cuando quieras

Puedes recorrer la portada, explorar necesidades publicadas, consultar el directorio de instituciones verificadas y leer la guía para donar sin crear una cuenta.

Con una cuenta de donante puedes registrar compromisos reales. La mensajería privada y el seguimiento GPS todavía no están disponibles; no se simulan en la interfaz.

Transparencia

Cada acción que ves lleva a un destino real. Las funciones que aún no están disponibles no se simulan.

Créditos visuales

Imágenes con procedencia declarada

Las ilustraciones de DonaConecta fueron proporcionadas por el usuario para este proyecto. La herramienta o el modelo de creación no fue declarado y su uso está autorizado únicamente en esta plataforma.

Se usan como recursos visuales, nunca como evidencia de donaciones, personas identificables, organizaciones verificadas ni estadísticas. Las cuatro primeras ilustraciones conservan sus originales y tienen derivados optimizados; las ocho imágenes incorporadas en el rediseño actual se publican sin derivados adicionales.
