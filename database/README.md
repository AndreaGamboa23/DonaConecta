# Base de datos — DonaConecta

Esta carpeta contendrá los scripts T-SQL versionados, el modelo relacional normalizado
hasta tercera forma normal (3FN) y las instrucciones de instalación de la base de datos.

## Entorno previsto

- Instancia local: `.\\SQLEXPRESS`
- Base de datos propuesta: `DonaConectaDB`
- Controlador: `ODBC Driver 18 for SQL Server`
- Autenticación local: Windows
- `Encrypt=yes` y `TrustServerCertificate=yes` solo en el entorno local autorizado
